# ImageSearch API

ImageSearch is a backend REST API built with Java and Spring Boot.  
The project allows uploading images with metadata (name and tags) and retrieving them by their unique identifier.

The main goal of this project is to serve as the backend for a future image search application, where users will be able to search photos based on name or tags.

## Features

- Image upload with name and tags
- Image storage in a database
- UUID-based image identification
- Image rendering directly in the browser

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Docker
- Lombok

## Project Status

This project is under active development.  
New features such as image search, pagination and frontend integration will be added in future iterations.
